# 🗄️ Database Management Systems (DBMS): The Complete Bilingual Guide (English & தமிழ்)

Welcome to the ultimate Database Management Systems (DBMS) study guide! This repository contains comprehensive, extremely detailed notes covering the entire **91-video DBMS playlist by Neso Academy**. 

Every single video is mapped to a dedicated section with all corresponding mathematical models (Relational Algebra/Calculus), diagrams, functional dependencies, normal forms, and SQL queries. All concepts are explained in **English** (for formal study and interviews) and **Tamil (தமிழ்)** (using everyday analogies to help you master database concepts with ease).

## 💻 Practical SQL Scripts (`/sql-scripts`)

To help you practice SQL hands-on, the repository includes ready-to-run SQL script files:
1. **[schema.sql](./sql-scripts/schema.sql)**: Complete database schema with Primary Keys, Foreign Keys, unique/check constraints, and default values.
2. **[queries.sql](./sql-scripts/queries.sql)**: Detailed SQL querying scripts showcasing aggregates, grouping (`GROUP BY`, `HAVING`), natural joins, outer joins, and nested subqueries (correlated and uncorrelated).
3. **[triggers.sql](./sql-scripts/triggers.sql)**: Stored procedures, PL/pgSQL functions, and Triggers showing how databases automate workflow execution.
