# 🗄️ Database Management Systems (DBMS): The Complete Detailed Guide

Welcome to the ultimate Database Management Systems (DBMS) study guide! This repository contains comprehensive, extremely detailed notes covering 91 lectures of database systems curriculum. 

Every single topic is mapped to a dedicated section with corresponding mathematical models (Relational Algebra/Calculus), illustrative data tables, functional dependencies, normal forms, transaction schedules, and PL/SQL scripts. All explanations are written in detailed, technical **English** with concrete examples.

## 💻 Practical SQL Scripts (`/sql-scripts`)

To help you practice SQL hands-on, the repository includes ready-to-run SQL script files:
1. **[schema.sql](./sql-scripts/schema.sql)**: Complete database schema with Primary Keys, Foreign Keys, unique/check constraints, and default values.
2. **[queries.sql](./sql-scripts/queries.sql)**: Detailed SQL querying scripts showcasing aggregates, grouping (`GROUP BY`, `HAVING`), natural joins, outer joins, and nested subqueries (correlated and uncorrelated).
3. **[triggers.sql](./sql-scripts/triggers.sql)**: Stored procedures, PL/pgSQL functions, and Triggers showing how databases automate workflow execution.
